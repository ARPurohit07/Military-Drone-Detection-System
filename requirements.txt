# Install with:
#
#   uv venv
#   uv pip install torch>=2.6.0 torchvision>=0.21.0 --index-url https://download.pytorch.org/whl/cu124
#   uv pip install -r requirements.txt
#
# torch and torchvision are installed FIRST and from the CUDA index, in a separate
# command. Two reasons:
#
# 1. On Windows the default PyPI torch wheel is CPU-only. A CPU build turns a
#    ~40 min training epoch into something unusable, and it fails silently - the
#    code runs, just 50x slower. The cu124 build is what the throughput figures in
#    the README were measured on.
#
# 2. The PyTorch index also hosts unrelated packages at old pins (requests 2.28.1
#    among them). uv resolves each package from the first index that offers it, to
#    avoid dependency-confusion attacks, so listing the CUDA index here as an
#    --extra-index-url makes the resolve fail. Scoping that index to the one
#    command that needs it is safer than relaxing the index strategy globally.
#
# Verify CUDA before training:
#
#   .venv/Scripts/python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
#
# It must print a version with a +cu suffix and True.
